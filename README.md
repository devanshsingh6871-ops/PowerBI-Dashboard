# PowerBI-Dashboard
RetailPulse Sales Dashboard | Power BI

📊 Project Overview

An interactive sales dashboard developed using Microsoft Power BI for my Descriptive Analytics practical. This project analyzes retail sales data to identify trends and generate meaningful business insights.

🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

📈 Key Features

- Total Sales and Quantity KPIs
- Sales by Region and Product Category
- Monthly Sales Trends
- Year-over-Year (YoY) Growth Analysis
- Interactive Region Filters
- Year-to-Date (YTD) Analysis

🎯 Objective

To apply data cleaning, data modelling, DAX calculations, and visualization techniques to understand retail sales performance.
